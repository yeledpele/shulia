# שוליית האופה 🍩

סטודיו בעברית שבו ילדים בונים משחק הרפתקה מסוג "הצבע ולחץ" (Point & Click) לבד, בלי לכתוב קוד: סיפור, דמויות, שיחות, סצנות, חידות וציורי פיקסלים.

המשחק הראשון שנבנה בו: **שוליית האופה**. חנוכה בעיר, והשוליה צריך לאסוף תשעה מצרכים כדי שהאופה זלמן יטגן סופגניות.

**לשחק ולבנות בדפדפן:** https://yeledpele.github.io/shulia/

## מה יש בסטודיו

| סטודיו | מה עושים בו |
| --- | --- |
| מעבדת הסיפור | כותבים את הסיפור, יוצרים דמויות ושיחות עם בחירות |
| בונה העולם | גוררים דמויות וחפצים לסצנות, יציאות, מה קורה כשלוחצים, יום/לילה |
| סטודיו רקעים | בונים רקע מחלקים מוכנים (חלונות, עצים, בתים, שמיים) |
| סטודיו פיקסלים | מציירים דמויות, חפצים ורקעים פיקסל אחרי פיקסל, עם שכבות |
| מעצב החידות | חוקים בסגנון "כאשר… / אם… / אז…", חפצים, משימות |
| בדיקת משחק | משחקים במה שבנינו, עם מצב בדיקה שמסביר למה משהו לא עובד |

הכל נשמר לבד בדפדפן (IndexedDB). אין צורך בחשבון או בשרת.

## להריץ על המחשב

```bash
npm install
npm run dev      # סביבת פיתוח
npm run build    # בונה קובץ HTML אחד ב-dist/index.html
```

## איך זה בנוי

- `src/model` — מבנה הנתונים של משחק (JSON), המשחק לדוגמה והציורים שלו
- `src/logic` — מנוע החוקים: מחליט מה קורה בכל לחיצה ומסביר בעברית למה
- `src/runtime` — מנוע המשחק (Phaser 3), שמריץ כל משחק שנבנה בסטודיו
- `src/editor` — הסטודיו (React + TypeScript)

העורך והמשחק נפרדים: העורך רק כותב את קובץ המשחק, והמשחק רק קורא אותו.

## מה עוד מתוכנן

- סטודיו אנימציה (פריים אחרי פריים)
- ייצוא וייבוא של משחק לקובץ, כדי להעביר אותו בין מחשבים ולשתף
